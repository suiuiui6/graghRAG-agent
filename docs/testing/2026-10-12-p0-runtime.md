## 范围与根因

- `backend/server.py` 仅修改 `_iter_mineru_runtime_sources`：旧扫描只检查任务目录一级，无法读取新 `output/mineru/<完整task_id>/result/`。
- 新扫描优先采用有效 `result`，保留旧一级有效产物，按任务目录修改时间倒序，恢复文件名使用任务目录名。仅扫描这两个固定位置，不递归进入 `.working-*`，同时拒绝输出根、任务目录、结果目录、产物的符号链接/junction及解析越界，产物必须是文件。
- 根据主负责人追加指派，修改 `backend/mineru_client.py` 的 `download_and_extract`：旧逻辑解压后直接发布，没有产物校验。现在要求真实 `full.md` 和至少一个 `*_content_list.json`，所有匹配内容列表均为普通文件且 JSON 顶层为 list，失败返回 `PIPELINE_MINERU_PARSE` 并保留未发布 working 目录。
- 新增 `backend/tests/test_p0_runtime_sources.py`；扩充 `backend/tests/test_p0_mineru_isolation.py`，原有并发成功夹具补齐合法 content list，未删除或减弱原断言。

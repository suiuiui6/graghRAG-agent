主agent读取27份真实回答及各题完整目标范围，形成`provisional-adjudication.json`与`provisional-item-scores.json`。没有追加API judge；均是单agent暂定标注，待独立复核。下表描述核心发现，不是最终准确率统计。

特别可追溯案例：

- D3-SUPERVISOR B1把1805–1878的路由决策说成属于11015–11170的4.1范围，同时漏掉两项。两个oracle基线恢复四项。原响应`024-response.json`，对照`025/026-response.json`。
- D1-COST B1的168来自正文18054–18316，问题限定摘要；五个核心摘要成本本来已在输入。说明不仅有检索漏项，也有生成阶段范围污染。1970不能跟168一起自动判错。
- D2-DATA B1根本没有4.5相关文本，却生成正确的4.5 million及原句引用。与潜在模型记忆一致，但机制未被验证，不能证明具体预训练暴露。标准答案匹配不等于证据忠实。

## Gold需要修订，但不能事后静默改答案

原Gold保持31条单agent草案。D1摘要字符927–941明确写“电网支撑价值为1970元/吨”。问题写“吨氨成本类经济指标”，1970是支撑价值而非直接成本，但具有同单位，三组回答都将它纳入。因此它是类别边界/Gold完整性争议，不能机械视作B2/B3 false positive。本轮不对该题给exact-set总分，不事后删除返回或扩充gold来美化指标。

D2-ATTENTION的第三项QKV不是本节像前两项那样逐一明示，需明确允许的语义推断边界。原gold也不能用宽松anchor命中掩盖字段支持问题。所有题的逐条评分保留为暂定，不报告总体准确率、显著性或总体失败率。

## 对研究方向的有限裁决

已观察到类似范围列举失败出现在D1与D3，而非仅历史单一题；也观察到证据缺项、范围越界和正确答案无输入支持这几类区别。**这足以把问题保留为研究候选，不足以证明可推广的新方法缺口。** D2是知名论文，D3是内部规范，三类源都不是独立盲测样本。

本轮两个简单oracle范围基线消除了已核对的目录/工具缺项和Supervisor越界；没有证据支持立即包装复杂GraphRAG新算法。不能据此宣称生产当前版本仍失败或已经修好：生产B0、实际自动范围路由、相等实际token预算、新文档留出和直接先行工作均未执行/完成，期刊层次仍不判定。

下一步：先独立复核Gold的条目、范围类别与字段支持标准，再冻结现版本B0及自动范围路由的小规模对照设计；追加远程调用须另获范围确认。本轮不追加请求。

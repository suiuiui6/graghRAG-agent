# Skill Evaluation Reading Guide

Use this directory as the interpretation layer for evaluation artifacts that live under [`docs/skill-evaluation`](../skill-evaluation/README.md).

## Reading Order

1. Start with [`docs/skill-evaluation/README.md`](../skill-evaluation/README.md) for evidence-handling rules.
2. Read [`harness-engineering-layer-mapping.md`](./harness-engineering-layer-mapping.md) before editing prompts, benchmarks, or eval expectations that mention Layer 0-6.
3. Open the concrete iteration artifact only after the terminology is clear.

## Scope

- Use the files under `docs/skill-evaluation/**/outputs/**` as immutable evidence snapshots.
- Put interpretation, terminology mapping, and editorial corrections in `docs/superpowers/`.

## 1. 发明名称

一种基于版面坐标接地的多模态文档知识图谱构建与可溯源问答方法、装置、设备及存储介质。

可选备选名称：

- 一种面向多模态文档的实体接地知识图谱构建与可溯源问答方法
- 一种基于文档版面坐标映射的知识图谱检索增强生成方法
- 一种面向非结构化文档的 grounded KG-RAG 问答方法

## 2. 技术领域

本发明涉及人工智能、自然语言处理、知识图谱、文档智能解析、检索增强生成和多模态文档处理技术领域，尤其涉及一种将文档解析结果、实体抽取结果、知识图谱节点以及问答引用结果统一映射到原始文档页码和版面坐标区域的方法。

## 3. 背景技术

现有基于大语言模型的文档问答系统通常将 PDF、Word、PPT、图片等文档转换为文本块，再通过向量检索或关键词检索召回上下文，由大语言模型生成回答。该类方法在实际应用中存在如下问题：

1. 文档解析结果与大模型实体抽取结果之间缺少稳定的位置映射关系，导致回答中的事实难以定位到原始文档页面。
2. 多模态文档中的表格、公式、图片说明、标题层级和版面坐标在纯文本化过程中容易丢失，降低后续问答结果的可验证性。
3. 普通知识图谱构建方法往往只保存实体及关系，未将实体节点与原始文档中的页码、版面坐标、内容块类型和接地状态绑定。
4. 普通 RAG 系统可能返回自然语言引用或粗粒度文本片段，但难以支持前端在原始文档中对答案依据进行精确高亮。
5. 当大模型抽取出无法在原文中定位的实体时，现有系统缺少统一的过滤或降权机制，容易使幻觉实体进入知识图谱和问答链路。

因此，需要一种能够在文档解析、实体抽取、知识图谱构建和问答生成之间建立统一接地链路的技术方案，使答案中的关键事实能够回溯到原始文档的具体页码和版面坐标区域。

## 4. 发明目的

本发明旨在解决以下技术问题：

- 如何将多模态文档解析得到的内容块坐标与全文文本字符区间建立映射关系。
- 如何将大模型实体抽取得到的片段内字符区间转换为原始文档中的页码和版面坐标。
- 如何基于已接地实体构建可溯源知识图谱。
- 如何在问答阶段优先使用可接地知识图谱节点生成带证据链的答案。

本发明的目的在于提供一种多模态文档知识图谱构建与可溯源问答方法，使系统能够输出包含答案文本、知识图谱节点标识、页码、版面坐标和接地状态的问答结果。

## 5. 技术方案概述

本发明的方法包括以下步骤：

1. 获取待处理文档的解析结果，所述解析结果包括文档全文文本、内容块列表以及各内容块对应的页码、版面坐标和内容块类型。
2. 根据内容块列表中的文本内容在文档全文文本中的字符位置，构建位置映射表。
3. 按照标题层级或语义段落边界对文档全文文本进行切分，得到多个文档片段，并记录各文档片段在文档全文文本中的全局字符偏移。
4. 对文档片段进行实体抽取，得到包含实体类别、实体文本、实体属性和片段内字符区间的抽取结果。
5. 根据文档片段的全局字符偏移，将片段内字符区间转换为全文全局字符区间。
6. 基于位置映射表查询全文全局字符区间对应的页码、版面坐标和内容块类型，生成带接地状态的实体。
7. 根据带接地状态的实体构建知识图谱节点，并根据共现关系、同类型关系或顺序邻接关系构建知识图谱边。
8. 接收用户查询，基于知识图谱执行检索和问答生成，输出包含答案文本、引用节点、页码和版面坐标的可溯源问答结果。

## 6. 系统组成

本发明可包括以下模块：

### 6.1 文档解析模块

用于接收 PDF、Word、PPT、Excel、图片或 HTML 等多模态文档，并输出文档全文文本、内容块列表和版面布局信息。

输出示例：

- `full.md`：按照阅读顺序组织的全文 Markdown 文本。
- `content_list`：平铺内容块列表，包括文本块、表格块、公式块、图片说明块等。
- `layout`：页面级或块级版面结构信息。

### 6.2 位置映射模块

用于将内容块列表中的文本内容匹配到全文文本中，建立字符区间与页码、版面坐标、内容块类型之间的对应关系。

位置映射表可包括：

- 字符起始位置
- 字符结束位置
- 内容块索引
- 页码
- 版面坐标
- 内容块类型
- 标题层级
- 内容块文本

### 6.3 文档切分模块

用于根据标题层级或语义段落边界将全文文本切分为多个文档片段，并记录每个文档片段的全局字符偏移。

可选策略：

- 按一级标题和二级标题切分。
- 对短片段进行合并。
- 对无标题文档使用全文作为一个片段。

### 6.4 实体抽取模块

用于对每个文档片段执行实体抽取，得到实体类别、实体文本、实体属性和片段内字符区间。

实体类别可包括：

- 文档元信息
- 章节标题
- 模型组件
- 数值指标
- 数据集
- 方法
- 定义
- 公式
- 参考文献
- 结论或论断

### 6.5 实体接地模块

用于将实体抽取得到的片段内字符区间转换为全文全局字符区间，并基于位置映射表确定实体对应的页码、版面坐标和内容块类型。

当实体缺少字符区间或无法匹配位置映射表时，将其标记为未接地实体；当实体可匹配到页码和版面坐标时，将其标记为已接地实体。

### 6.6 知识图谱构建模块

用于将实体转换为知识图谱节点，并构建实体之间的关系边。

节点字段可包括：

- 节点标识
- 实体类别
- 实体文本
- 实体属性
- 页码
- 版面坐标
- 接地状态

边类型可包括：

- 同页共现关系
- 同类型顺连关系
- 顺序邻接关系

### 6.7 可溯源问答模块

用于接收用户自然语言查询，基于知识图谱执行检索、邻域扩展和答案生成，并返回答案文本及其对应的引用节点、页码和版面坐标。

可选策略：

- 优先检索已接地节点。
- 对结构类问题执行图谱邻域遍历。
- 对指标类问题优先检索数值指标节点。
- 对答案中的关键事实绑定 source node、page index 和 bbox。

### 6.8 前端高亮模块

用于根据问答结果中的页码和版面坐标，在原始文档预览区域高亮对应证据区域。

## 8. 详细实施方式

### 8.1 文档解析与内容块提取

输入待处理文档后，调用文档解析服务生成全文文本和内容块列表。内容块列表按阅读顺序排列，每个内容块携带页码和版面坐标。对于表格块、公式块和图片块，可分别提取表格标题、公式文本、图片说明或占位文本作为可匹配文本。

### 8.2 构建位置映射表

遍历内容块列表，提取每个内容块的可显示文本，并对空白字符进行归一化处理。随后在全文文本中查找对应文本的位置，若完整文本无法匹配，则使用文本前缀进行匹配。匹配成功后，记录全文字符区间和内容块对应的页码、版面坐标及内容块类型。

当内容块无法在全文文本中匹配时，可使用前一映射项的结束位置作为近似起点，生成弱映射项，以保证后续流程不中断。

### 8.3 文档片段切分与偏移记录

根据内容块中的标题层级识别切分边界，将全文文本切分为多个文档片段。每个文档片段记录：

- 片段标识
- 片段标题
- 标题层级
- 片段起始字符位置
- 片段结束字符位置

若片段长度小于预设阈值，则合并到前一片段中。

### 8.4 实体抽取

将文档片段输入实体抽取模型，得到实体类别、实体文本、实体属性和片段内字符区间。实体抽取模型可以为大语言模型、信息抽取模型或规则模型。

### 8.5 实体坐标接地

对每个抽取实体，若其存在片段内字符区间，则将片段内字符区间加上文档片段的全局字符偏移，得到全文全局字符区间。随后查询位置映射表，获得对应的页码、版面坐标和内容块类型。

若实体不存在字符区间，或无法在位置映射表中找到对应内容块，则设置：

```text
grounding_status = "ungrounded"
page_idx = null
bbox_norm = null
```

若匹配成功，则设置：

```text
grounding_status = "grounded"
page_idx = matched_segment.page_idx
bbox_norm = matched_segment.bbox
```

### 8.6 知识图谱构建

将每个接地实体或未接地实体转换为知识图谱节点。知识图谱节点保留实体类别、实体文本、实体属性、页码、版面坐标和接地状态。

关系边可通过以下规则构建：

1. 对同一页内相邻或近邻实体构建共现关系。
2. 对同一实体类别的连续实体构建同类型关系。
3. 对抽取顺序相邻的实体构建顺序邻接关系。

### 8.7 可溯源问答

接收用户查询后，根据查询类型选择知识图谱检索策略。例如：

- 数值或指标问题优先检索指标类节点。
- 结构或关系问题优先执行图谱邻域遍历。
- 概念或定义问题优先检索定义类节点。
- 综合问题执行多类型混合检索。

系统基于检索到的知识图谱节点和关系生成答案，并将答案中的关键事实关联到对应的节点标识、页码和版面坐标。

### 8.8 结果展示

问答结果可包含：

- 答案文本
- 引用节点列表
- 子图结构
- 页码
- 版面坐标
- 相关性分数

前端可根据页码和版面坐标在文档预览区高亮答案依据。

## 9. 有益效果

与现有技术相比，本发明至少具有以下有益效果：

1. 能够将大模型抽取实体重新映射到原始文档页面和版面区域，提高问答结果的可验证性。
2. 能够在知识图谱节点中保留页码、版面坐标和接地状态，使知识图谱兼具结构化检索能力和原文溯源能力。
3. 能够过滤或区分无法接地的实体，降低幻觉实体进入问答链路的概率。
4. 能够支持前端基于页码和版面坐标高亮原始证据区域，提升用户对答案依据的审查效率。
5. 能够兼容文本、表格、公式、图片说明等多种内容块，适用于论文、合同、财报、技术文档和病历等多类文档。

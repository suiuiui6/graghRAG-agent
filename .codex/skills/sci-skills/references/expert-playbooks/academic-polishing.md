# Academic Polishing Playbook

## Diagnose first

Classify problems as grammar, clarity, cohesion, logic, terminology, translation, journal convention, or scientific-content risk. Language repair may proceed; scientific-content repair requires author evidence or a separate task.

## Levels

- `LIGHT`: grammar, punctuation, spelling, and obvious ambiguity.
- `STANDARD`: sentence structure, paragraph flow, concision, and terminology.
- `STRUCTURAL`: argument order and paragraph function while preserving the approved scientific commitment.
- `TRANSLATION`: meaning-first Chinese-English or English-Chinese translation with terminology control.

## Locked content

Before editing, lock numbers, units, equations, citations, gene or material names, statistical meaning, causal strength, negative findings, limitations, and validation scope. If prose and evidence conflict, flag the conflict rather than smoothing it away.

Return a clean version plus an original/revised/reason table when changes are substantial, a terminology ledger, scientific-risk notes, and a locked-content audit. Do not manufacture journal style rules or use a remote grammar service.

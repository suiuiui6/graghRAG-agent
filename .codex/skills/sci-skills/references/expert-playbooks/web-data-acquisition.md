# Web Data Acquisition Playbook

## Data-sufficiency gate

Proceed only when reviewed evidence is `ABSENT` or `INSUFFICIENT`, the critical gap cannot be repaired through cleaning, derivation, coding, or existing linkage, and web evidence is methodologically appropriate. Stop for `UNKNOWN` or `SUFFICIENT`.

## Lawful source ladder

Verified user-held data; official webpage downloads; open repository or archive files; licensed manual exports; authorized authenticated exports; permitted public-page collection as a documented last resort. Never call an external API or bypass login, paywall, CAPTCHA, technical protection, explicit prohibition, or access limit.

## Research-to-data mapping

Map question to construct, observable signal, unit, field, source, and analysis use. Define population, time, geography, language, inclusion, exclusion, sampling, stopping, volume, provenance, output schema, rights, privacy, bias, and cost.

Require a pilot of 1–3 pages or roughly 10–50 records. Inspect parsing, identifiers, duplicates, missingness, scope, bias, permissions, and raw preservation. Do not scale or clean until the pilot and user audit pass. Return a collection plan, pilot record, provenance ledger, rights notes, known-bias summary, and cleaning handoff.

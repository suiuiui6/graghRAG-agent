# Data and Code Availability Playbook

## Inventory

List raw and processed data, code, models and configuration, source data behind figures, questionnaires, protocols, metadata, third-party material, and restricted or sensitive material. Map every figure and claim to an available or justified unavailable source item.

## Repository and package plan

Choose among a field repository, general repository, controlled-access repository, institutional repository, supplement, or specific justified restriction. Define file structure, data dictionary, provenance, versioning, environment, licence, access conditions, embargo, and dataset citation.

Use ordinary official webpages for current repository facts. Record a DOI, accession, or stable link only after returned evidence proves it exists. Do not default to “available on reasonable request” for convenience.

Audit FAIR metadata, machine readability, identifiers, documentation, licensing, reuse, and reproducibility. Apply ethics, consent, law, Indigenous data governance, confidentiality, commercial licence, and security limits where relevant. Repository creation and upload use the manual companion.

# Scientific Figures Playbook

## Classify first

- `RESULT`: quantitative, experimental, statistical, model-performance, microscopy-measurement, survival, ROC, heatmap, or other evidence-bearing pixels.
- `EXPLANATORY`: algorithm, framework, workflow, mechanism, or study-design explanation.
- `ENHANCEMENT`: graphical abstract, overview, or visual aid without result claims.

## Result gate

Render result figures only when real data or verified result files, variable and metric definitions, declared transformations, executable Python or R source, actual execution evidence, and input-to-pixel traceability are present. Never use invented values or image generation for result pixels.

## Proposal and consent

Before rendering any explanatory or enhancement figure, show the manuscript location, purpose, content, evidence role, panel decomposition, reference-image relationship, required author materials, and generation route. Obtain explicit user approval. For complex models or experiments, propose an overview plus module-level panels instead of forcing one crowded figure.

## Deliverables and QA

Provide a figure plan, data profile, transformation log, executable source, output files, captions, provenance, and QA report. Check numerical traceability, panel labels, axes, units, legends, statistical marks, accessibility, crop, resolution, font size, consistency, and journal format. Final manuscript insertion requires rendered QA and user approval.

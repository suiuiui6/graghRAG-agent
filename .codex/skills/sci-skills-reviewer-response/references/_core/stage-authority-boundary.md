# Stage Authority Boundary

An expert may diagnose specialist readiness and recommend a repair or pass candidate. It may not modify the authoritative project state, declare a stage passed, skip upstream evidence gates, or reinterpret a direct task as authorization to complete the whole paper.

The orchestrator validates:

- task identity and contract version;
- source and execution evidence;
- requested outputs and quality checks;
- returned manual-operation evidence;
- the current stage's acceptance criteria;
- consistency with the project state and one next action.

On mismatch, retain the current stage and issue a bounded repair task. If an expert is unavailable or incompatible, use a clearly labelled provisional fallback and do not pretend the expert ran.

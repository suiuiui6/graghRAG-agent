# Zero External API Policy

The SCI-Skills mainline and every expert must work without third-party APIs, keys, tokens, SDKs, endpoints, remote-model services, or mandatory account configuration.

Allowed routes are user-provided files, platform-native search or browsing, ordinary official webpages, local computation, local software already available, and files manually exported by the user. Optional local adapters may improve automation but may not become prerequisites.

If a local capability is unavailable:

1. state what cannot be executed;
2. preserve the strongest useful intermediate artifact;
3. provide a local script, structured plan, or manual operation companion when appropriate;
4. keep the paper project and stage state intact.

Never request passwords, verification codes, cookies, session data, private keys, access tokens, or institutional credentials. Do not silently add packages or instruct a beginner to configure infrastructure before starting the paper workflow.

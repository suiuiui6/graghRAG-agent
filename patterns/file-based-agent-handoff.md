# 通过文件交接 Agent 工作

适用：多 Agent、多个 AI 工具或会话之间需要接续同一仓库任务。

方法：AGENTS.md 指定约束与读取顺序；docs 索引定位有效规范；memory/index.md 定位当前任务与下一步；日期记录保留动作、依据、实际验证及阻塞。新 Agent 重新检查工作区并读取任务材料后执行，结束时由任务负责人汇总更新记忆。只引用规范，不复制第二份权威内容。

最小交接内容：任务目标、阶段、输入版本、负责文件、输出、已决策事项、验证证据、阻塞和下一步。模板见 [工作流规范](../docs/governance/agent-workflow.md)。

来源：[2026-10-12 记录](../memory/2026-10-12.md)、[本次设计](../docs/design/2026-10-12-agent-workflow-design.md)。验证范围：本项目文档协议的建立与静态检查；真实跨工具恢复效果尚待实测，不能据此宣称已验证。

限制：索引过期、多人同时写记忆、报告与代码版本不匹配会破坏接续。指定主负责人更新索引，核验快照；文件不是自动同步服务，也不能保证 Agent 一定遵守。用于新项目时替换项目专属架构、命令和环境规则，先确认目标再检查/初始化 Git，不复制本项目专属蓝图。
